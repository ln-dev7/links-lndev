Connexion TikTok

Page technique de Creator Stats, l'outil de statistiques personnel de LN. Elle sert seulement à relier son compte TikTok à son tableau de bord. Rien n'est enregistré ici.

developers.tiktok.com → Creator Stats → Sandbox → Credentials. La clé client n'est pas secrète ; elle reste dans ce navigateur.

Ouvrir l'Action GitHub
  1. Copie le code (il ne sert qu'une fois et expire vite : fais-le tout de suite).
  2. Sur GitHub : Run workflow, colle le code dans « code », puis Run workflow.
  3. L'Action échange le code et enregistre le secret TT_REFRESH_TOKEN. C'est fini pour un an.
